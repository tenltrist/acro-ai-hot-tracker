# 未入选原因与漏选抽查

核对日期：2026-09-09。仅03融合本地预览，未发布、未改评分或采集频率。

## 本次试验

保留旧规则作为基线，为历史记录中的“其他留存资料”增加只读原因分组、事件级评分依据和30条逐条材料判读。不是新一轮抓取，不是全量AI精读，不创建付费API。

当前快照为2026-09-08，共2295条留存记录，242条入选、2053条其他资料。总览固定90天的146条入选信息保持不变。新增意见不能改变这些数字。

## 原因口径

| 主原因 | 当前无筛选数量 |
| --- | ---: |
| 其他基础分未过线 | 844 |
| 基础分未过线且有时效降分记录 | 804 |
| 专题类型排除 | 263 |
| ACRO相关性门槛 | 74 |
| 基础分未过线且有噪音扣分记录 | 61 |
| 来源仅观察 | 5 |
| 未命中公司且缺少业务动作 | 2 |
| 合计 | 2053 |

原因来自原始 selection_reason、reasons 与类型规则，不根据当前日期重算过去的分数。主要判定优先次序：已入选、来源观察、专题类型、相关性、公司/动作缺口、基础分。基础分项按已有日志先分时效、再分噪音、其余保留在普通基础分不足；时效与噪音可能同时存在，附加日志仍显示。因此804不能解释成“只改时效就会多入选804条”。

合并事件有任一入选报道即属于入选；其他事件如果各报道原因不同，使用“多篇报道的原因不同”，而非重复计数。缺少判定字段显示“判定依据不足”，不凭分数猜原因。

263条专题资料的旧 selection_reason 被后续函数写成“未达到日报基础分数”。页面以实际保留的类型排除日志解释，并提示旧文案的局限。原始字段不修改；下次后台生成仍存在该文案问题，需要后续单独修正。

## 抽样与意见

目的性挑选30条：8条专题资料、4条观察源、6条近期产品/合作、7条时效降分、5条噪音/边界对照。不是随机抽样，不能给出全库漏选率或证明规则准确率。

- 建议复议5条：FRONTEO/Chiome合作、Promega Ki-67产品、Bio-Techne工程化蛋白、Sino SuperNuclease Pro、Promega/Countable Labs联合营销。
- 适合档案留存14条：科研/视频、临床登记及历史合作/组织/设施资料等，不自动当作近90天新闻。
- 维持非精选6条：估值评论、财务背景、果冻产品和当前材料无法证明ACRO直接关联的仪器动态。
- 需补证或拆分5条：AMED资助名单、误标funding的会议公告、科研制药组织调整、混合新闻标题页、涉及Merck不同业务身份的合作。

14条补充了可追溯的网页、公告或官方目录证据，另外16条限于已有标题/摘录/登记元数据。补充链接也不都代表全文读取：具体支持范围逐条记录。ClinicalTrials网页仅返回空壳，论文DOI及一条媒体列表未取得正文，均未冒充已读。

配置：`config/admission_audit.json`；生成：`scripts/build_admission_audit.cjs`；网页资料：`web/admission-reviews.js`。每条意见绑定原记录的签名，标题、摘录、分数、类型、公司命中等变化后停止展示旧意见。生成脚本遇到快照变更或记录变化会拒绝给旧意见重新盖章。重建静态网页不会自动重新判读。
