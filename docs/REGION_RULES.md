# 地区判读与统计规则

日期：2026-09-09；规则版本：2026-09-09.4；状态：仅03融合本地预览。

## 本次覆盖

2026-06-11至2026-09-08共146条入选新闻，按记录ID去重。146条均已判读，继续补证后为126条有地区依据、16条不限定地区、4条证据不足。默认总览为上述90天146条；30天对照范围66条分别为61、4、1。不是146条都有具体国家。

这是地区判读，不是146篇全文精读，也不是全库2295条标注。资料读取深度逐条写明：存档标题与摘录、公告正文、公开段落、索引或视频文字简介。没有读到的正文、附件和视频不能声明已读。

## 三种结果与处理进度

| 判定结果 | 含义 | 统计位置 |
| --- | --- | --- |
| 有地区依据 | 有与本次事件直接相关的地理依据，包括已明确的大区或全球权利范围 | 具体大区与范围证据分层展示 |
| 内容不限定地区 | 已读材料是未限定地域的技术方法、一般讨论或公司整体披露 | 独立数量，不画成地区，不等于全球 |
| 地区证据不足 | 可用材料不完整，或本次事件的地点、权利范围未披露 | 独立数量及具体原因，不指定国家 |

三者互斥，相加等于当前新闻数。另行计算“已判读／尚未判读”，有判读记录不代表一定取得地区依据；后续新增新闻不会自动标成已判读。

## 页面位置与浏览范围

顶部采用“总览／周看板／月看板／历史记录”四个浏览入口。总览固定显示快照截止日近90天的 daily 或 immediate 入选记录；周月按既有自然周期和事件合并规则查看全部已保留事件。历史页分“全部记录／入选信息／其他留存资料”，所有记录都已保存。合并事件只要有一篇报道为 daily 或 immediate 就入选，其余为其他留存资料；缺失层级明确标注入选状态未确认，不推断被规则拒绝。后台 archive 只表示筛选层级，不表示其他记录尚未保存。两个子分类互斥且覆盖全部记录，沿用同一组地区等筛选。入选信息再按可信发布日期分为近90天内、范围外、未确认日期，三项可点击查看且相加等于当前筛选下的入选总数。未知日期不拿抓取时间替代，仍被保留。不改变采集频率，全部记录也不等于完整历史。

产品／技术、地区及商业事件是顶部独立筛选维度，与监测对象、公司、检索、类型和相关性一起在浏览入口间保留。“客户”只是客户类监测账户的简称，不修改销售关系。总览地区图只显示范围、可点击数量条形、分区明细和缺失状态入口；周月地区图复用相同地区定义，按本页保守合并事件计数和下钻。准入、划分、判读进度、原因及已保存证据集中在“规则中心 → 分类与业务输出 → 地区判读与统计”，不再堆在图旁。图的横轴是新闻／事件数量，不是项目工期。

## 判读顺序

1. 确认新闻主事件及涉及公司，区分申请、批准、签约、计划和完成。
2. 识别与主事件直接相连的地点、产品市场、监管辖区、合作机构、交易主体法域、试验或活动范围。
3. 记录地区关系类型，不能把合作方所在地说成实际研发地点，把计划试验范围说成已完成入组。
4. 使用原标题、可用来源摘录或补充原始公告。国内、海外、会议名须结合公告主体及具体事件核对；活动需匹配名称、年份和会址。
5. 对保存的判断绑定新闻ID及标题守卫。已存判读优先，可补充或否定关键词结果；切到仅标题／摘录模式不启用判读。材料更新须重新核对，当前没有自动全文变化检测。

## 可以与不可以使用的依据

- FDA、EMA/CHMP、PMDA/厚生劳动省、TGA必须关联具体监管动作；IND缩写本身不自动映射美国。辖区分组不外推批准到分组内其他国家。
- 公司国籍、总部简介、联系地址、电头、媒体名、网页语言、国家子域、宣传词与现有AI摘要，不单独作为地区依据。
- 若主事件本身就是某地总部或工厂开业，该地点可计入。不能把整句含总部的实际设施新闻一律丢弃。
- 既往批准、其他适应证、独立投资项目、比较背景、明确排除地区不混进本次事件。
- 技术内容不因网站语言就归日本或中国。全球供应／许可须有明确范围；没有地区信息不等于全球。
- 不跨文章无依据复制结论。同一事件多篇报道可以复用已核对来源，必须确认具体事件匹配并注明复用范围。

## 地区分组

国家和城市映射到既有业务地区，同一条新闻同一地区只计一次。中国及港澳台、欧洲、北美是展示分组，不表示辖区等同。本看板北美为美国与加拿大，墨西哥归拉美。

一级图表只展示亚太、北美、欧洲、拉丁美洲、中东、非洲，零命中折叠。亚太是父级，展开可见日本、中国及港澳台、韩国、东南亚、南亚、大洋洲，以及原文仅明确亚太的记录。日本与澳大利亚同篇出现，在亚太只计一条，不把子项之和当父级新闻量。

全球和仅明确亚洲的证据不再画成一级地区条形，收在“跨地区范围证据”。全球指明确的许可、供应、试验等业务边界，不代表在各国均有已发生事件；不因全球字样向全部国家加一。原文只有亚洲时不编造国家，也不把亚洲无条件改写为APAC。原始16个证据代码保留，本次没有增加底层分类。

总览和周月筛选共用父子结构。勾选亚太等于勾选既有7个下属代码的并集，子项部分选中时父级为半选；“全部地区”包括全球范围、不限定地区和证据不足，不等于“全球业务范围”。

同维度多选取并集，不同维度取交集。地区条形图采用同一筛选及记录ID去重；跨大区新闻可进入多个分项，分项之和可能大于新闻数。范围证据与地区也可能来自同篇，不能相加。图表点击按同一组ID下钻，保留面包屑及返回；周月页仍按原有保守事件合并口径，不改变其合并规则。
